# БД ФСИТ — военно-политическая работа

Сайт учёта личного состава. База лежит в папке проекта (`data/pgdata`). **Node.js ставить не нужно** — движок уже лежит в `runtime\node`.

## Как запустить на любом компьютере

1. Скопируйте **всю папку** `socdem` на диск компьютера (NTFS, не флешка).
2. Дважды щёлкните `Открыть базу.bat`.
3. В браузере откроется вход.

Имя пользователя: `admin`. Если пароль ещё не меняли, он в файле `data\credentials.txt`. После первого входа сайт попросит задать свой пароль.

Карточки и фото лежат в папке `data/` и сохраняются сами, через пару секунд после правки.

Повторный щелчок по `Открыть базу.bat` просто снова открывает сайт.

Чтобы выключить и точно записать копию: на сайте кнопка **«Сохранить и выключить»** или файл `Выключить базу.bat`. После этого чёрное окно и браузер можно закрыть.

Подробно для преподавателя: файл `ИНСТРУКЦИЯ.txt`.

## Режим разработки

Два терминала:

```bash
cd backend
npm install
npm run dev
```

```bash
cd frontend
npm install
npm run dev
```

Сайт: http://127.0.0.1:5173

## Стек

- **Frontend:** React, React Router, Vite
- **Backend:** Express, встроенный Node в `runtime/node`
- **БД:** PGlite, файлы в `data/pgdata`
